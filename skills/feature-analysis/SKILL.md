# 特征分析技能

## 目标
判断业务现象是否由特征口径、数据质量或分布漂移引起，并给出可验证的证据。

## 分析清单

1. **口径核对**
   - 特征定义、计算窗口、更新频率、数据源；
   - 是否存在上游表结构或枚举值变更。

2. **质量检查**
   - 空值率、默认值占比、异常值（负数、超界、时间穿越）；
   - 同一实体在 T+1 与实时链路的一致性。

3. **分布分析**
   - 分位数（P50/P90/P99）、均值、方差；
   - 与基线周期对比，计算 PSI / KS；
   - 分箱边界是否仍能区分好坏样本。

4. **与规则联动**
   - 命中样本在该特征上的分布 vs 未命中样本；
   - 阈值附近是否存在堆积（说明阈值敏感）。

## 结论模板
- 特征是否异常：是 / 否 / 证据不足
- 异常类型：口径变更 / 数据缺失 / 分布漂移 / 分箱失效
- 影响范围：受影响规则、客群、渠道
- 建议：修数、回补、调阈值、换特征
