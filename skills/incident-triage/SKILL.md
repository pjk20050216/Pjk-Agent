# 异常排查技能

## 分级
| 级别 | 判定 | 响应 |
|---|---|---|
| P0 | 大面积误拦截 / 资金损失 | 立即止损，回滚，15 分钟内同步 |
| P1 | 单渠道指标异常 / 客诉集中 | 30 分钟内定位，2 小时内给方案 |
| P2 | 局部样本异常 | 当日定位 |
| P3 | 咨询类 | 常规处理 |

## 排查顺序（先止损，后归因）

1. **确认影响面**：影响客群、渠道、金额、时间窗；
2. **检查最近变更**：规则、特征、模型、名单、上游数据；
3. **二分定位**：按渠道/客群/规则拆分指标，找到异常集中点；
4. **日志取证**：调用 `log_search` 拉取决策日志，保存快照到 `/logs`；
5. **复现**：用沙箱脚本在样本上复现；
6. **止损方案**：回滚 / 降级 / 加白 / 人工复核；
7. **复盘**：写入 `/reports/incident_<时间戳>.md`，沉淀到长期记忆。

## 输出要求
- 必须明确「当前是否仍在影响」；
- 止损动作需人工审批并记录审批单号；
- 复盘包含时间线、根因、改进项、责任人。
