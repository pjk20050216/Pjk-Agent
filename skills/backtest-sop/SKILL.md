# 回测 SOP

## 输入
- 规则版本（变更前 / 变更后）
- 样本集（时间窗、客群、渠道、样本量）
- 评估指标（命中、误杀、漏放、金额、通过率）

## 步骤

1. **固定样本**：变更前后必须使用同一份样本快照，记录样本 ID 与行数。
2. **基线回放**：先跑变更前版本，产出基线指标。
3. **实验回放**：跑变更后版本，逐条对比差异样本。
4. **显著性判断**：
   - 样本量 < 1000 时，结论标注「置信度低」；
   - 指标变化需给出绝对值与相对值。
5. **异常样本抽检**：随机抽取 20 条差异样本，人工可复核。
6. **产出报告**：写入 `/reports/backtest_<时间戳>.md`，包含样本说明、指标表、差异样本、结论、风险提示。

## 判定标准
- 误杀率上升超过 0.5 个百分点 → 不建议发布；
- 漏放率上升超过 0.3 个百分点 → 需补充规则；
- 金额影响超过阈值 → 升级审批。

## 注意
- 不得用变更后样本自证；
- 不得省略基线；
- 沙箱执行的脚本必须来自 `/workspace`，执行结果回写 `/logs`。
