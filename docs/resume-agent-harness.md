# 项目简历：风控策略智能运维多智能体系统

## 项目介绍

面向风控策略运维复杂任务，基于 Agent Harness 运行时能力层，从一句业务问题出发，主 Agent 自动规划任务并异步委派特征分析、规则配置、测试验证、异常排查、知识检索、数据采集 6 个专业子 Agent；通过虚拟文件系统、上下文隔离、可插拔中间件、Skills、Redis + Milvus 记忆、OpenSandbox 沙箱、人工审批与 Kafka 链路追踪，形成从问题定位、策略验证、审批材料生成到结果复盘的闭环。

## 核心工作

- **多智能体任务编排**：将原 LangGraph 单 Agent 状态机重构为 Multi-Agent，主 Agent 产出任务清单，按依赖分层用 asyncio 并发委派 6 个专业子 Agent；实现任务状态机、失败重试、阻塞传播与跨会话恢复，解决长链路上下文爆炸、串行执行和失败放大问题。

- **上下文工程与虚拟文件系统**：设计 VFS 作为 Agent 工作记忆，抽象七类目录；写入采用临时文件 + 原子替换，按 SHA-256 生成版本快照，支持历史、diff、搜索与跨平面 promote；子 Agent 仅回传 ≤1200 字结构化摘要 + 文件引用，大结果全部落 VFS，降低主上下文污染与 Token 消耗。

- **可插拔中间件 Hook 链**：实现洋葱式中间件，在模型调用、工具调用、文件读写、任务状态变更节点注入缓存、重试、RBAC、PII 脱敏、敏感动作审批、链路追踪与审计；文件操作经代理，解决治理逻辑散落、权限与脱敏不一致的问题。

- **主机 + 沙箱双层安全平面**：构建主机 + 沙箱双层执行平面，优先适配 OpenSandbox 并支持本地受限子进程降级，结合命令白名单、高危拦截、超时 kill、网络/文件隔离与高风险动作人工审批，解决 Agent 执行不可信和线上变更合规问题。

- **双层记忆与 Skills 渐进式披露**：Redis 保存短期对话、任务计划、审批断点；Milvus 沉淀长期经验、策略模板、用户偏好与历史案例；SKILL.md 按“元数据 → 正文 → 资源”三级加载；任务结束自动复盘蒸馏排查模式与提示模板，实现领域能力复用与自我进化。

- **可观测与扩展体系**：对任务执行的关键节点做全链路埋点，事件以 JSONL + Kafka 双通道上报，Kafka 不可用时自动落本地缓冲；提供 Java 工具扩展桥，Java 工具由 Python 自动发现并纳入权限、审批与审计。
